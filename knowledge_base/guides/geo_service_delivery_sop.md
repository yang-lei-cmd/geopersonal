```markdown
## Technical Audit Checklist

### Infrastructure Level（基础设施层）
- [ ] robots.txt 配置正确（未屏蔽AI爬虫）

- [ ] Mobile-Friendly Test通过
- [ ] Canonical URLs正确配置
- [ ] Hreflang标签（如有多语言）

### On-Page Level（页面级）
- [ ] Title Tags: 标题含品牌名+核心价值主张+目标关键词
- [ ] Meta Descriptions: 150-160字符，包含行动号召
- [ ] H1 Tags: 每页唯一H1，包含核心关键词
- [ ] Internal Linking: 关键页面间有良好的链接结构
- [ ] Image Alt Text: 所有图片有描述性alt文本
- [ ] URL Structure: 简洁、语义化、无参数污染

### Schema Markup Level（结构化数据层）
- [ ] Organization Schema（企业主体声明）— P0必做

### Content Quality Level（内容质量层）
- [ ] 核心产品/服务页面有完整的技术规格说明
```

### 3.2 Geo Tracker初始化配置

```markdown
## Geo Tracker Setup Guide

### Sheet 1: Raw Test Data
Headers:
Date | Brand | Query | Platform | Mentioned(1/0) | Position | Total Brands | Sentiment | Key Claim | Source URL | Confidence | Schema Hints | Score | Notes

Scoring Formula (0-11 points per query):
Score = (Mentioned × 3) + ((6 - Position) × 1) + (Sentiment × 1 if positive else 0) + (HasSchema × 1) + (KeyClaimMatches × 2)

### Sheet 2: Summary Dashboard
Formulas:
- Citation Rate = SUM(Mentioned=1) / Total Tests
- Average Position Score = AVERAGE(Position) converted to 0-10 scale
- Positive Sentiment % = COUNTIF(Sentiment="positive") / Total
- Schema Coverage % = COUNTIF(SchemaHints!="") / Total
- GEO Health Score = Citation Rate×0.4 + Position Score×0.25 + Sentiment×0.2 + SchemaCoverage×0.15

Grade Mapping:
≥80 = A | 70-79 = B+ | 60-69 = B | 50-59 = C+ | <50 = C

### Sheet 3: Platform Comparison
Platform columns: ChatGPT | Gemini | DeepSeek | Doubao | Qianwen | Kimi
Row metrics: Citation Rate | Avg Position | Positive Sentiment | Schema Coverage

### Sheet 4: Monthly Trend
Weekly aggregation with delta calculations vs previous period

### Sheet 5: Query Type Analysis
Categories: Recommendation | Comparison | Review | Tutorial | Pricing | Alternative

### Sheet 6: Competitor Benchmark
Side-by-side competitor data for gap analysis
```

## Phase 4: 策略制定与实施规划

### 4.1 Gap Analysis四步法

```
Step 1: 数据聚合
├─ 汇总基线测试的所有原始数据
├─ 按查询类型分组分析（Recommendation/Comparison/Tutorial等）
└─ 按平台分组分析（哪个平台表现最好/最差）

Step 2: 差距识别
├─ Platform Gaps: 哪些平台明显落后于竞品
├─ Query Type Gaps: 哪类商业意图查询完全缺失
├─ Content Gaps: 哪些关键信息未被AI提取（FAQ/Comparison/Product Details）
└─ Authority Gaps: 缺乏哪些第三方权威来源背书

Step 3: 优先级排序（RICE框架）
├─ Reach: 修复后能影响多少查询/多少流量
├─ Impact: 对整体Citation Rate的提升幅度
├─ Confidence: 我们对该修复有效性的信心程度
└─ Effort: 完成修复所需的工作量
RICE Score = (Reach × Impact × Confidence) / Effort

Step 4: Action Plan生成
├─ P0 (High RICE, Low Effort): 立即执行
├─ P1 (High RICE, High Effort): 计划执行
├─ P2 (Medium RICE): 排期执行
└─ P3 (Low RICE): 暂缓或放弃
```

```markdown
### 通义千问优化版（ToB场景）
- 标题: 正式商务风（如 " enterprise Customer Success Framework Whitepaper"）
- 格式: 白皮书/报告格式
- 重点: 商业价值论证、ROI计算、实施路径
```

### 7.2 Renewal Trigger Checklist

```markdown
## When to Initiate Renewal Conversation

Initiate renewal discussion when ANY of these conditions are met:

□ Client has been active for 60+ days with consistent monitoring
□ Monthly trend shows positive trajectory (Citation Rate ↑ OR Position ↓ OR Health Score ↑)
□ Client has asked about "next steps" or "what's next" organically
□ We've completed the first full month of reporting
□ Client referenced the report positively in internal meetings
□ Competitive landscape has shifted (new entrant, algorithm update)

✗ We haven't delivered on any committed deliverables yet
```
