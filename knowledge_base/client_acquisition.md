# GEO客户获取与项目管理实战手册

## 第一部分：获客渠道搭建

### 1.1 内容获客体系

#### 平台分布策略
| 平台 | 内容形式 | 频率 | 目标客户群 |
|-----|---------|------|-----------|
| LinkedIn | 长文分析+案例拆解 | 每周2篇 | B端决策者 |
| Twitter/X | 短观点+互动讨论 | 每日1条 | 营销从业者 |
| 知乎 | 深度问答+专栏文章 | 每周3篇 | 国内决策者 |
| 公众号 | 干货推送+案例故事 | 每周1篇 | 国内中小企业 |
| YouTube | 视频教程+直播Q&A | 每两周1期 | 技术型客户 |

#### 爆款内容公式
```
标题结构：[数字]+[痛点词]+[解决方案] + [时间承诺]
例如："7天提升AI搜索引用率300%的实操指南"

开头钩子：用惊人数据或反直觉结论抓住注意力
主体结构：
1. 痛点共鸣（30%）
2. 方案框架（40%）
3. 详细步骤（20%）
4. 工具推荐（10%）

结尾CTA：引导预约咨询或下载资源
```

## 第二部分：销售流程标准化

### 2.1 初次接触脚本

#### Cold Email Template
```
Subject: Quick question about your AI search visibility

Hi [Name],

I noticed that when searching "[industry keyword]" on ChatGPT, 
your competitors are getting cited but you're not appearing. 

This is likely costing you significant organic traffic as AI 
search usage grows 300% YoY.

I specialize in helping businesses like yours appear in AI-generated answers. 
Would you be open to a quick 15-minute call this week?

Best,
[Your name]
GEO Specialist | [Company]
```

#### 电话开场白
> "您好[姓名]总，我是专注AI搜索优化的顾问，今天冒昧来电是想分享一下我们最近帮[同类企业]在ChatGPT引用率上提升了3倍的经验，大概需要占用您3分钟时间介绍一下背景，如果您感兴趣我们可以深入聊聊。"

### 2.2 需求调研问卷模板

#### 标准问卷内容
```
【基本信息】
1. 公司名称及官网：
2. 主营业务及目标客户：
3. 当前主要流量来源：□搜索引擎 □社交媒体 □广告 □其他___

【现状评估】
4. 是否了解过AI搜索优化？ □完全不了解 □听说过一些 □已有一些尝试
5. 目前品牌在AI对话中的出现情况如何？
   □几乎不被提及 □偶尔出现但不准确 □有时被引用但非首选
6. 主要竞争对手是谁？他们目前在线表现如何？

【痛点挖掘】
7. 当前获客成本是多少？目标降低成本多少？
8. 是否有因"不在AI搜索结果中"而丢单的案例？
9. 内部团队对AI优化的认知程度如何？

【期望设定】
10. 理想情况下希望达到什么效果？
    □被AI推荐为首选 ✓　　□至少出现在前3位参考
    □建立行业权威形象 ✓　　□降低获客成本50%以上
11. 预算范围和投入意愿：
    □ 5K以内试水　□ 5-15K正式起步　□ 15K以上深度合作
12. 期望的时间框架：□ 1个月内启动　□ 3个月内见效　□ 长期年度合作
```

### 2.3 Proposal 撰写框架

#### 提案结构
```
封面：客户Logo + 我们的Logo + 提案日期

第一部分：执行摘要（1页）
- 核心发现：当前AI可见度缺口
- 主要机会：可获取的流量增量
- 投资回报：预期ROI和时间框架

第二部分：问题分析（2-3页）
- 竞品对比分析（图表展示）
- 根因诊断（技术+内容+权威性三个层面）
- 损失量化（潜在的流失收入估算）

第三部分：解决方案（3-5页）
- 第一阶段：技术基础建设（2-3周）
- 第二阶段：内容策略重构（4-6周）
- 第三阶段：权威网络建设（持续）

第四部分：实施方案（1-2页）
- 详细的里程碑计划
- 责任分工矩阵
- 风险评估与应对

第五部分：报价与条款（1页）
- 服务费明细
- 付款节奏
- 保证条款

附录：案例分析、团队介绍、参考资料
```

## 第四部分：客户服务与续约

### 4.1 NPS收集时机

| 节点 | 时机 | 问题模板 |
|-----|------|---------|
| 初体验 | 第一周结束 | "从0到1的了解过程中，我们会如何改进？" |
| 阶段性成果 | 一个月结束时 | "目前的进展是否达到了您的预期？" |
| 季度回顾 | 每季度末 | "如果向同行推荐我们，您会怎么说？" |
| 续约前 | 合同到期前1个月 | "基于过往合作体验，您认为我们的价值体现在哪里？" |

### 4.2 续约谈判策略

#### 价值重述框架
```
过去成果（What We Did）：
- 列举具体达成的KPI
- 对比基准线的进步幅度

未来机会（What's Next）：
- 新的算法变化带来的新机会
- 竞品动态及我方应对策略
- 可扩展的合作领域

套餐升级选项：
- Tier 1: 基础维护（延续现有服务）
- Tier 2: 增长加速（新增渠道/内容类型）
- Tier 3: 战略合作（全案GEO+品牌定位）
```
