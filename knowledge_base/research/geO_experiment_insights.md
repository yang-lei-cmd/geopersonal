## 🔬 Experiment 1: 已有品牌从零启动 GEO 覆盖（SEM Rush实测数据）

**研究设计**: 15个商业意图关键词 × 4平台（ChatGPT/Claude/Gemini/Perplexity）  
**周期**: 约8周，手动逐日追踪  
**核心结论**: 37.01%峰值可见度；来源类型比流量价值更重要

### 关键数据点

| 指标 | 数值 |
|------|------|
| Peak Keyword Presence | 37.01% (April 29) |
| Platform Citation Totals | ChatGPT 148 > Claude 96 > Gemini 87 > Perplexity 64 |
| Top Single Source | Indeed SEO Listicle — **190 mentions**（超过其他所有来源总和） |
| Source Type Breakdown | Listicles 72.4% / PR 24.1% / Guest Posts 3.5% / Owned Site <1% |
| Half-Life of Sources | ~30天（一半来源在30天内停止被引用） |

### ⭐ 五大洞察（可直接指导实践）

#### 1. Peer Set Effect — 实体关联效应显著
当一篇清单文章将目标品牌与 Lily Ray、Aleyda Solis 等公认专家并列时，该品牌的AI引用量最高。移除这些知名实体后，表现几天内急剧下降。**AI模型通过上下文实体来判断可信度**。

→ **行动项**: 优先争取能与你已有的权威资源并列的放置机会。

#### 2. Comparative Content 碾压 Advocacy Content
自有清单页更新为包含主要竞争对手的版本后，引用量从 **4次跃升至49次**（增长12.25倍）。同日可见度曲线从22飙升至峰值95。

→ **行动项**: 不要只写"关于我的内容"，写"我和谁一起出现在最佳列表中"的内容。

#### 3. Source Authority Hierarchy（权威性层级）
```
Government/Education > News Publications > Industry-Specific Sites > General Sites
```
Phase 1中行业相关placements配合PR效果极强；Phase 2中写的更好的通用站点列表几乎没有可见度。质量可以放大强位置，但无法弥补弱位置。

→ **行动项**: 先确保源权威性达标，再追求数量。

#### 4. Depth > Frequency（深度胜过频率）
前5篇简短清单几乎零效果；唯一全面深入的长文持续获得引用。**一个高质量source值十个中等质量source**。

→ **行动项**: 宁可做一篇10,000字终极指南，不做十篇500字速览。

#### 5. SERP Visibility → LLM Visibility 强关联
当某个品牌在Google搜索结果中缺席，它在ChatGPT答案中也几乎完全缺席。**SEO不是过时的——它是GEO的基础设施**。

→ **行动项**: 确保核心landing page在Google已排名，这是AI引用的必要非充分条件。

## 🔬 Experiment 2: Cold Start Test — SaaS外链服务商从零到298次提及

**研究设计**: 无AI存在度的SaaS公司，15个商业关键词 × 6平台（新增Google AI Mode + Grok）  
**周期**: 30天（May 30 - Jun 28）  
**结果**: 298次出现，21.75%新用户在AI通道中到达

### 平台分布（总量298次）

| Platform | Mentions | % Total | Key Insight |
|----------|---------|---------|-------------|
| Gemini | 104 | 34.9% | 领先平台 — 对长尾查询友好 |
| Google AI Mode | 95 | 31.9% | 紧随其后 — 依赖Web搜索 |
| Claude | 59 | 19.8% | 高意图集中 — 商业词更强 |
| ChatGPT | 32 | 10.7% | 引用量少但有转化价值 |
| Grok | 4 | 1.3% | 可忽略暂不投入 |
| Perplexity | 4 | 1.3% | 低量但有标杆客户案例 |

### ⭐ 五大冷启动洞察

#### 1. Zero-to-298 in 30 Days 证明方法论可行
没有任何基础品牌的公司在30天内达到可观的AI引用量。**GEO不像传统SEO那样需要年累积期**。

#### 2. Listicle Placement is King（清单置放为王）
第三方可用placements贡献了85.8%的引用量，自有内容仅14%，PR几乎为0。但三者构成系统效应：Listicle引入主张 → PR放大 → Guest Post延伸。

#### 3. 1个Perplexity引荐 = 1个付费客户
尽管Perplexity只有4次引用（1.3%），其中一个引荐直接转化为付费客户。**低量高价值 ≠ 不重要**。

#### 4. Time-to-Citation 差异极大（1-18天）
被引最快的placement当天生效，最慢的是自有清单页（18天）。这意味着单点测量不可靠，需要至少4周的观察窗口。

#### 5. Exact-Match Keywords 依然重要
"Best LLM SEO Consultant"获得了18次出现，而语义相近的"Best AI SEO Consultant"几乎为零。高价值商业关键词需要专门的资产来承接。

## 🎯 综合战略建议（基于全部实验数据）

### Priority Tier 1: 立即执行（最高ROI）
1. **建立Listicle Placement战略** — 目标确保证券类媒体（Indeed SEO等）的先发优势
2. **构建Comparative Content** — 将所有"关于我们"页面改造为"关于我们+竞品对比"
3. **完善Technical Foundation** — Schema覆盖≥80%，确保Core Web Vitals达标
4. **建立Keyword Asset库** — 为每个高价值精确匹配关键词创建专门内容

### Priority Tier 2: 近期建设（中期积累）
5. **Guest Post系统化** — 每周至少2篇专业平台投稿
6. **HARO/Expert响应** — 每天关注专家咨询机会
7. **Entity Connection Strengthening** — About页面Organization schema + Expert Author bios

### Priority Tier 3: 持续监测
8. **Weekly Manual Testing Cadence** — 使用Geo Tracker模板记录趋势
9. **Monthly Competitor Benchmark** — SOV-AI对比差距分析
10. **Platform Strategy Tuning** — 根据各平台表现调整资源分配（如Claude高意图书写 vs Gemini长尾覆盖）

## 💡 关键公式总结

```
Citation Volume = f(Source Authority, Content Depth, Peer Association, Exact Match Relevance, Freshness)

Owned Content Multiplier ≈ 0.14 (self-published contributes 14% of total)
Third-Party Listicle Multiplier ≈ 0.86 (earned placements drive 86% of total)
Half-life of a Citation Source ≈ 30 days
Time-to-Citation Range: 1-18 days (median ~7 days)

Comparison Content Impact: 12.25× increase when adding competitor context
Peer Association Impact: Visible decline when removing known experts from listicles
```
