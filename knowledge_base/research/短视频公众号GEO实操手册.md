> 更新时间：2026-11-18 | 适用平台：视频号/抖音/公众号/小红书/B站

## 🎯 核心原则（来自Princeton GEO论文实证）

### ❌ 错误做法：关键词堆砌
```
❌ "最好的CRM软件 CRM系统 客户管理 销售管理 进销存 ERP 免费试用"
    ↑ 这种写法对AI引用几乎无效，甚至产生负面信号
```

### ✅ 正确做法：自然语言陈述事实
```
✅ "XYZ CRM帮助300+中小企业提升销售转化率40%，支持免费14天试用"
    ↑ 具体数字+品牌名+价值主张=AI高引用概率结构
```

## 📝 第一部分：视频号/抖音GEO优化公式

### 一、标题结构公式（潮视新创实测有效）

#### 基础公式
```
【问题句】+【数字限定】+【结论承诺】

示例：
- 「小公司税务筹划怎么做？3个合法省税步骤」
- 「抖音算法2026最新规则是什么？5个变化直接影响流量」
- 「公众号涨粉快吗？这3个方法让我7天增粉5000」
```

#### 进阶公式（情感触发型）
```
【痛点场景】+【反常识结论】+【数字背书】

示例：
- 「为什么你的视频没人看？90%的人忽略了这一步」
- 「AI不会取代你，但会用AI的人会 — 3个真实案例证明」
```

### 二、文字层优化检查清单（必做）

| 元素 | 长度建议 | 必须包含 | 禁止项 |
|------|---------|---------|--------|
| **标题** | 15-30字 | 问题句+数字+关键词 | 纯表情符号/无意义字符 |
| **简介** | 100-200字 | 品牌名+核心价值+行动引导 | 纯emoji/链接堆砌 |
| **字幕** | 完整覆盖音频 | 关键术语原词重现 | 大量同义词替换导致AI无法识别实体 |
| **封面文字** | ≤10字 | 大字体高对比度 | 复杂图案遮挡文字 |

### 三、评论区GEO策略（常被忽视的高价值区）

**原理**: AI会读取高赞评论作为「社会证明+补充信息」信源

**操作步骤**:
```
1. 发布后1小时内，用小号提问关键问题
   示例："请问这个软件有免费版吗？" → 作者回复含关键词

2. 置顶一条「争议性提问」激发讨论
   示例："你们觉得AI会取代设计师吗？我觉得…"

3. 用主号回复带关键词的评论
   示例："感谢@小明 关注，我们确实提供14天免费试用"
```

## 🔍 第二部分：微信生态GEO差异化策略

### 一、各平台信源偏好矩阵（千百顺GEO独家数据）

| AI平台 | 主要信源偏好 | 权重占比 | 最佳内容类型 |
|--------|-------------|---------|-------------|
| **豆包** | 今日头条+头条系媒体 | 头条生态 60% | 新闻综述/政策解读 |
| **腾讯元宝** | 微信公众号+视频号 | 微信生态 55% | 深度分析/操作教程 |
| **DeepSeek** | 问答社区+技术博客 | CSDN/知乎 50% | 技术问题解答/代码片段 |
| **Kimi** | 财经商业媒体+研报 | 36氪/虎嗅 45% | 行业分析/商业案例 |
| **文心一言** | 百度百科+百度系内容 | 百科 40% | 词条式定义/科普内容 |

### 二、元宝生态专项策略（日活5000万+/月活1.14亿）

#### 为什么元宝值得重点投入？
```
1. 搜索入口独占性：微信右上角搜索直接接入元宝
2. 社交裂变潜力：视频号内容可通过聊天分享直达元宝结果
3. B端决策影响：企业采购常通过元宝查询解决方案
4. 竞争相对蓝海：头部玩家布局较少，早期进入者占位优势明显
```

#### 元宝GEO四阶段落地路径（千百顺SOP）

**Phase 1: 基线审计（W1）**
- [ ] 查询品牌在元宝中的首次提及率
- [ ] 记录当前排名位置（前3/中3/后段/未出现）
- [ ] 分析现有信源分布（公众号文章/新闻报道/UGC论坛）

**Phase 2: 账号建档（W2-4）**
- [ ] 公众号完成主体认证+行业分类标注
- [ ] 视频号绑定企业微信+添加地理位置标签
- [ ] 百度百科创建企业词条（含成立时间/主营业务/创始人）

**Phase 3: 内容矩阵铺设（M1-M3）**
```
内容配比建议（每周发布节奏）：
├─ 深度长文（2000字+）× 1篇 — 建立权威叙事
├─ 操作教程（图文步骤）× 2篇 — 解决具体问题
├─ 案例复盘（Before/After对比）× 1篇 — 提供社会证明
└─ 行业观点（热点评论）× 2篇 — 保持活跃度
```

**Phase 4: 监测复盘（持续）**
- [ ] 每周查询一次品牌词在元宝的表现
- [ ] 月度对比Citation Rate变化趋势
- [ ] 季度审视Top信源是否有新增竞品挤占

## 🔄 第三部分：跨平台内容适配策略（V哥AI增长方法论）

### 核心洞察：抖音 vs 视频号引用路径完全不同

```
抖音引用链路：
抖音短视频 → 头条搜索索引 → 豆包AI回答引用

视频号引用链路：
微信视频号 → 搜狗搜索索引 → 腾讯元宝AI回答引用
          ↓
         公众号文章 → 微信搜一搜 → 元宝引用增强
```

### 五平台内容适配模板（同一素材拆5版）

| 平台 | 标题风格 | 正文长度 | 核心关键词 | 配图要求 |
|------|---------|---------|-----------|---------|
| **抖音** | 悬念反问+数字 | 短平快(30秒口播) | 口语化+热词 | 动态字幕突出金句 |
| **视频号** | 痛点场景+解决方案 | 中长(1-3分钟) | 搜索导向长尾词 | 封面图含大字标题 |
| **公众号** | 干货合集+案例故事 | 1500-3000字 | SEO友好型关键词组 | 配图3-5张+图表 |
| **小红书** | 情绪共鸣+对比反差 | 800-1500字 | emoji辅助的口语化 | 多图轮播+文字贴纸 |
| **B站** | 硬核测评+知识密度 | 5-15分钟长视频 | 专业术语+英文缩写 | 标题栏时间戳标注 |

### 实操案例：同一GEO知识内容的五平台分发

**原始内容（公众号长文）**：
```
标题：《中小企业如何用AI工具降本增效？3个实战案例》
正文：2500字深度分析，含流程图+ROI计算公式
核心关键词：AI降本增效/中小企业数字化转型/GEO优化
```

**拆解适配版**:

| 平台 | 改编版标题 | 核心调整点 |
|------|-----------|-----------|
| 抖音 | 「AI帮你省钱？这3个公司每个月少花2万」 | 开头3秒抛利益点，中间穿插数据可视化动效 |
| 视频号 | 「传统企业转型失败？看完这3个成功案例再决定」 | 专家出镜口播，评论区置顶「详细方案见公众号」 |
| 小红书 | 「打工人必看！AI神器让你提前下班✨附工具清单」 | 表情包丰富，每段≤3行，文末tag #AI工具 #职场效率 |
| B站 | 「从0到1搭建AI办公自动化｜附全套Prompt模板」 | 屏幕录制实操演示，章节跳转标注时间戳 |
| 知乎 | 「中小企业数字化转型有哪些坑？过来人总结3条血泪教训」 | 先讲失败案例建立信任，再引出解决方案 |

## ⚡ 第四部分：一键检查清单（可直接复用）

### 视频发布前自检（5分钟快速核查）

```
□ 标题格式：问题句+数字+结论？
□ 简介字数：100-200字，含品牌名和行动引导？
□ 字幕完整性：全文覆盖无缺失段落？
□ 评论区预埋：是否用小号提问了3个关键问题？
□ 话题标签：添加了3-5个精准话题而非泛泛热门标签？
□ 封面文字：是否清晰可读无遮挡？
□ 发布时间：是否在目标平台活跃高峰时段？
   - 视频号：早7-8点 / 午12-13点 / 晚20-22点
   - 抖音：午11-13点 / 晚19-23点
   - 公众号：早8-9点 / 晚21-22点
```

### 周度GEO健康度监测（每月1次深度检查）

```
□ Citation Rate查询：
   - 工具：用手动测试法（参考 manual_testing_guide.md）
   - 查询词：品牌名+品类词+竞品对比词
   - 目标：≥60%（SaaS类）、≥50%（通用服务类）

□ 信源分布审计：
   - 哪些平台在批量引用你的内容？
   - 是否有竞品占据Top Position？
   - 是否有负向内容（差评/吐槽）上榜？

□ 关键词霸屏度检查：
   - 搜索品牌名时，前5条结果是否均为自有资产？
   - 如果没有，哪些第三方媒体在抢占？

□ Schema标记有效性：
   - 使用Google Rich Results Test检测
   - FAQ/Article/HowTo标记是否正确渲染？
```

## 📊 第五部分：效果衡量指标体系

### 核心KPI定义

| KPI名称 | 计算公式 | 基准值(SaaS类) | 优秀值 |
|---------|---------|---------------|--------|
| **Citation Rate** | 被引用次数÷总查询次数 | ≥60% | ≥80% |
| **Position Score** | (1/Rank₁ + 2/Rank₂ + ...)/N | ≥3.0 | ≥4.0 |
| **Positive Sentiment %** | 正面提及÷总提及 | ≥70% | ≥85% |
| **Schema Coverage** | 已标记页面数÷总页面数 | ≥50% | ≥80% |
| **GEO Health Score** | 加权综合评分（详见geO_kpi_framework.md） | ≥60分(B级) | ≥80分(A级) |
