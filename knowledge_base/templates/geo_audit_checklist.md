# GEO审计检查表 - 完整版

## 使用指南
本检查表可用于：
1. 自我学习练习（用你自己的网站）
2. 免费诊断（给朋友或熟人项目练手）
3. 商业提案附件（展示专业度）
4. 月度审计追踪（记录优化进度）

## A. 技术基础审计 (权重25%)

### A1. SSL与HTTPS
- [ ] 网站已启用HTTPS（锁图标存在）
- [ ] 所有HTTP链接自动重定向到HTTPS
- [ ] HSTS头已配置
- [ ] Mixed Content问题为零

### A2. Core Web Vitals
| 指标 | 阈值 | 实测值 | 状态 |
|-----|------|--------|------|
| LCP | < 2.5s | ___ | ☐通过 ☐需优化 |
| INP | < 200ms | ___ | ☐通过 ☐需优化 |
| CLS | < 0.1 | ___ | ☐通过 ☐需优化 |
| FID | < 100ms | ___ | ☐通过 ☐需优化 |

**测试工具：** Google PageSpeed Insights、Lighthouse

### A3. 移动端适配
- [ ] Mobile-Friendly Test通过
- [ ] 字体大小≥16px
- [ ] 按钮间距≥48x48px
- [ ] 视口viewport正确设置
- [ ] 无水平滚动条

### A4. 站点地图与索引
- [ ] Sitemap.xml存在且格式正确
- [ ] 已在Search Console提交
- [ ] robots.txt无阻断指令
- [ ] Canonical标签正确配置
- [ ] 无orphan pages（孤立页面）
