## 🟢 入门级服务（Lead Generation）

### GEO Health Check — 免费/低价诊断钩子

**定价**: 免费（作为获客钩子）或 $299一次性  
**目标客户**: 任何对AI搜索可见度感兴趣的中小企业主  
**转化路径**: 免费报告 → 付费深度审计 → 年度服务合同  

#### 服务内容
- 3个核心查询词 × 3个平台 = 9次AI回答测试
- Citation Rate + Position Score基线测量
- Schema覆盖初步扫描
- Top 3优先改进项建议
- 8页PDF简要报告

#### 交付物
```
📄 GEO Quick Scan Report (8页PDF)
├─ 执行摘要（1段）
├─ 三大核心指标现状（Citation/Position/Sentiment）
├─ 各平台表现对比（3×3矩阵）
├─ Top 3优先行动项
└─ 下一步服务推荐链接
```

#### 转化率预期
- 免费诊断 → 付费深度审计：约15-25%
- 付费深度审计 → 年度合约：约30-40%

## 🟡 标准服务包（Core Offerings）

### GEO Starter Package — 基础优化包

**定价**: $2,500 - $5,000 / 项目（一次性）  
**周期**: 4周  
**目标客户**: 中小企业（年收入$500K-$5M），首次尝试GEO  
**预计产出**: Citation Rate从基线提升至≥20%

#### 交付内容（按周分解）

| 周 | 工作项 | 交付物 |
|----|-------|--------|
| Week 1 | 技术基础审计 + Schema实施 | 审计报告 + Schema实施日志 |
| Week 2 | 首段直接回答优化（5个核心页面） | 内容优化变更单 |
| Week 3 | FAQ/HowTo内容创建（2篇） | 新内容 + Schema标记 |
| Week 4 | 基线复测 + 成果报告 | GEO Baseline Comparison Report |

#### 不含在包内
- Guest posting/PR建设
- 竞争性分析深度调研
- 持续监控追踪

### GEO Growth Package — 增长加速包

**定价**: $5,000 - $15,000 / 季度  
**周期**: 按季度签约（最低3个月）  
**目标客户**: SaaS公司、B2B服务公司，已有SEO基础但AI可见度不足  
**预计产出**: Citation Rate提升至30-40%，GEO Score进入B级  

#### 月度交付内容

| 模块 | 内容 | 频率 |
|-----|------|------|
| 技术维护 | Schema更新 + 性能监控 | 每周 |
| 内容创作 | 1篇Pillar Article + 2篇Support Content | 每月 |
| 权威建设 | Guest Post x2 + HARO响应x5 | 每月 |
| 竞品监测 | SOV-AI追踪 + Gap Analysis更新 | 每两周 |
| 进度报告 | Monthly GEO Dashboard + 策略调整建议 | 每月 |

#### 季度附加价值
- 4次深度AI平台策略会议（60分钟/次）
- 季度GEO健康评分提升≥10分承诺
- 未完成目标则免费延长1个月
